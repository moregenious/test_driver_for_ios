# 🍏 Дневник смен водителя (Driver Shift Diary — iOS & Backend)

Комплексное кроссплатформенное решение для водителей такси и курьеров: быстрый учет смен, расчет комиссии сервиса/парка, общей выручки и дохода **«на руки»**, с разделением по способам оплаты (наличные и банковская карта).

Проект включает в себя:
1. **REST API & Backend** (FastAPI, Python, Pydantic v2, потокобезопасное хранилище с защитой от дублей).
2. **Мобильное веб-приложение** (адаптивный интерфейс в виде кассового термочека, быстрый ввод, жесты свайпа).
3. **Нативное iOS-приложение** в папке `ios/` (полноценный проект для **Xcode / SwiftUI** с поддержкой системного меню **Share Sheet**, **Taptic Engine** тактильного отклика и офлайн-бандла).
4. **Набор автоматических тестов** (pytest, 19 тестов).

## ✨ Ключевые возможности

### 1. Финансовый учет смен
- **Чистый доход «на руки»** (`net_income = total_amount - total_commission`).
- **Общая выручка** («грязными»).
- **Комиссия сервиса/парка** (сумма и процентная доля).
- **Разделение по способам оплаты**:
  - Наличные: сумма и число заказов (`cash_amount`, `cash_trips`).
  - Карта (безнал): сумма и число заказов (`card_amount`, `card_trips`).
- **Финансовая точность**: расчет ведется через модуль `decimal.Decimal` с банковским округлением `ROUND_HALF_UP` во избежание погрешностей чисел с плавающей точкой (`float`).

### 2. Валидация и защита от дублей (Идемпотентность)
- Сумма поездки строго `> 0`.
- Время окончания строго позже времени начала (`end > start`).
- Проверка совместимости часовых поясов (ISO 8601).
- Комиссия неотрицательна и не может превышать сумму заказа.
- **Защита от повторных отправок**: при повторной отправке поездки (по уникальному `id` или по совпадению всех параметров `start`, `end`, `amount`, `payment`, `commission`) система **не создает дубликат**, а возвращает существующую запись со статусом `is_duplicate: true`.

### 3. Нативные фичи iOS
- **Системный Share Sheet (`UIActivityViewController`)**: при нажатии кнопки «📤 Чек» в приложении открывается нативная системная шторка iOS — чек можно сразу переслать в WhatsApp, Telegram, iMessage, AirDrop или сохранить в Заметки.
- **Taptic Engine Haptic Feedback**: тактильная отдача при нажатиях кнопок и переключении дат (`UIImpactFeedbackGenerator`).
- **Офлайн-режим**: статические ресурсы встроены прямо в бандл приложения, обеспечивая мгновенный запуск без белого экрана.

## 🚀 Быстрый запуск

### 1. Сервер и веб-версия (Python FastAPI)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python run.py
```

Адреса:
- **На компьютере (ПК)**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **С телефона по локальной сети**: `http://<IP_компьютера>:8000` (скрипт выводит точный адрес в терминал)
- **Интерактивная документация Swagger**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### 2. Запуск iOS-приложения в Xcode

1. Откройте файл `ios/DriverDiary.xcodeproj` в Xcode на macOS.
2. Выберите симулятор (например, **iPhone 15 Pro / iPhone 16**) или реальное подключенное устройство.
3. Нажмите **`Cmd + R`** (кнопка Play / Run).
4. Приложение скомпилируется и запустится.

### 3. Запуск автоматических тестов

```bash
python -m pytest -v
```

Все **19 тестов** проходят успешно:
- `test_summary.py`: проверка корректности расчетов выручки, комиссии, дохода «на руки» и разбивки по типам оплаты.
- `test_duplicates.py`: проверка защиты от дубликатов по ID и по телу запроса.
- `test_api.py`: валидация дат, фильтрация по дням, пагинация и обработка граничных случаев.
